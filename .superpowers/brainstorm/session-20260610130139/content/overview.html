Palma Explorer — Backend & Admin

Hur vill du strukturera plattformen? Välj den modell som passar bäst.

🏙️
CityPack Platform
En stad = ett CityPack = ett köp

A — CityPack-fokuserad

Appen är gratis att ladda ned. Varje stad (Palma, Barcelona, Rom...) är ett CityPack som kostar t.ex. 49 kr. Innehåller alla hotspots, ljud, bilder för den staden. Admin skapar och publicerar CityPacks via webbpanel.

💰 Tydlig intäktsmodell 🌍 Skalbart globalt 📦 Offline-stöd
🔓
Freemium
3 gratis hotspots, resten bakom betalmur

B — Freemium per stad

Varje stad har 3 gratis hotspots synliga för alla. Vill du ha alla 20+ hotspots låser du upp staden. Enkelt att prova innan köp. Admin styr vilka hotspots som är "gratis" i webbpanelen.

🪝 Låg tröskel 📈 Konvertering ⚡ Kräver konto
🎫
Prenumeration
Månads/årsabonnemang — alla städer ingår

C — Subscription

En fast månadskostnad (t.ex. 49 kr/mån eller 299 kr/år) ger tillgång till alla CityPacks. Enkelt för frekventa resenärer. Admin kan lägga till nya städer löpande utan ny betalning för befintliga kunder.

📅 Förutsägbar intäkt ♾️ Alla städer 🔐 Kräver auth
💡 Min rekommendation: A — CityPack som bas, med en gratis förhandsvisning (2-3 hotspots) för att locka köp. Enkelt att förklara, enkelt att prissätta, skalbart.
